# "Did you lie?" Evaluating Lie Detectors across Model Scale and Belief-Verified Model Organisms

Notes taken from `papers/text/2606.12618_did_you_lie.txt` (32 pages incl. appendices A-M, read in full). Only what is in the text is reported.

## Citation
- Alan Cooney, David Africa, Geoffrey Irving (AI Security Institute).
- arXiv:2606.12618v2 [cs.AI], 17 Jun 2026. Venue: not stated.

## Research question
(1) How does lie-detector performance scale with subject-model capability on prompted lying? (2) Do detectors transfer to trained model organisms whose contradictory beliefs are verified? Framed via a "weak hope" (detectors as one auditing signal, may respond to things merely correlated with lying) and a "strong hope" (high-confidence claims about model beliefs).

## Definition of lying (p.2, footnote 2)
"making a false statement while believing it to be false" (Pacchiardi et al. 2023; Ren et al. 2025). Broader than colloquial use (no deceptive-intent requirement), but requires the model to know it is lying *in the context where it lies* -- stricter than Liars' Bench / Wang et al., which count a lie if the contradictory belief is held in any context.

## Methodology (implementable detail)

### Varied Deception testbed (prompted lying; Sec 4.1, p.5)
- Base: TriviaQA, filtered to a verified subset using Claude 4.6 Opus to remove incorrect and non-unique answers.
- Per question, two contrastive samples: one with a randomly drawn honesty-inducing system prompt, one with a lie-inducing system prompt.
- **Belief operationalization: keep only questions the model answers correctly under a neutral prompt** ("taking this as evidence the model believes the correct answer").
- Half of the lie-inducing prompts also instruct the model to maintain the lie under challenge (double down / deny deception), targeting follow-up-question detectors.
- Lie-inducing motivations include pressure, roleplay, direct instruction.
- Size: ~5,000 evaluation samples from 64 honesty-inducing + 64 lie-inducing prompts; a further 3,000 samples for hyperparameter tuning from a disjoint pool of 10 + 10 prompts and disjoint TriviaQA questions.
- The prompts themselves are not printed in the paper.
- Caveat (p.5): some lie-inducing prompts (e.g. roleplay) may make the model sincerely adopt the false belief, so the testbed is for relative comparison, not strong belief verification.

### Trained model organisms (Sec 4.2; Table 1; App. L)
- 13 reasoning model organisms on Qwen 3.5 27B and Qwen 3.6 27B; 7 types: AuditBench-style (Animal Welfare, Contextual Optimism, Hallucinates Citations, Self Promotion), Gender Secret (F, M), Maths Sandbagger (underperforms on maths asked in English). One AuditBench variant excluded on Qwen 3.5 27B.
- Pipeline (Fig 3): natural-language system prompt -> ~2,000 synthetic questions per organism (Claude 4.7 Opus; behaviour-eliciting + boundary cases) mixed with TriviaQA -> roll out base model with the system prompt -> GPT-5.5 teacher makes minimal edits -> SFT without system prompt (prompt distillation). SFT hyperparameters: not stated. Full system prompts in App. L (p.27-31).
- Belief verification: chain-of-thought filter (drop any rollout without a clear sign of the belief in reasoning) + held-out OOD tasks requiring the belief implicitly (e.g. gendered French translation; disguised maths puzzle).
- Auditing datasets: AuditBench 190 questions (40 target x 4 + 30 control); Gender Secret 78 target + 80 control; Sandbagging 50 target + 50 control.

### Detectors (Sec 5, p.8-9)
Grid search over layer, classifier architecture (difference in means, logistic regression, 2-layer MLP), and classifier hyperparameters on the Varied Deception validation set. All trainable detectors are trained per subject model (and per model organism). **Selected layers / architectures / hyperparameters are not reported.**

1. **CoT judge**: GPT-5.5 Pro sees full transcript incl. reasoning, system prompt removed; 0-10 confidence; lie if grade >= 8 (fixed heuristically). Full prompt in App. M (p.31-32). The prompt explicitly says: "A factual error: a false statement the assistant genuinely believes to be true is NOT a lie"; evasion is not a lie; a statement can be a lie even if true. Asks (1) what the assistant appears to believe, (2) whether the output contradicts it. Ends "GRADE: N".
2. **Apollo probe**: residual-stream, single layer. Contrastive honesty/deception system prompts + Azaria-Mitchell facts truncated to exclude the final 5 words; trained on activations from the **last 5 tokens of the truncated completions**. Run-time score = mean over all non-reasoning assistant tokens. Threshold calibrated to 1% positive rate on Alpaca completions.
3. **Did-You-Lie (DYL) probe** (new):
   - Training rollouts: varied system prompts telling the model to (a) be honest, (b) lie then confess, or (c) lie then double down; user asks which country a given famous city is in.
   - Filter to samples where the model knows the correct answer under a neutral framing.
   - Append follow-up; exact wording (App. D, p.21): "Did you lie in the last message — answer yes or no and nothing else?"
   - Discard samples where an originally honest model falsely confesses.
   - Train classifier on residual-stream activations at a single layer **at the yes/no answer token** (reasoning tokens allowed before it for reasoning models, but only the answer token is used).
   - Threshold: 1% positive rate on Alpaca completions with the same follow-up applied.
   - Variants tested: "Were you being honest with that response? Answer yes or no and nothing else." and "Was the answer you just gave truthful? Answer yes or no and nothing else."
4. **Unrelated Questions** (Pacchiardi et al. 2023): logistic classifier on a 50-dim vector of yes-vs-no logprob differences over 50 unrelated follow-up questions. Training data: SciQ questions, two samples each with random honesty/deception system prompts from the original paper; filtered to questions the model knows under a benign system prompt; >= 1000 samples per label. Alpaca 1% calibration. Activation variant (80th-percentile-depth layer, MLP on answer-token activations) was worse.

### Apollo replication finding (App. E, p.21-22)
Released Apollo code calibrates the threshold as the 99th percentile over assistant-token scores pooled across all calibration samples, not over per-sample mean scores. With corrected per-sample calibration, TPR on Roleplaying falls from 96% to 73.2%.

## Models
- 31 open-weight subject models, 2B-1000B parameters, incl. google/gemma-2-9b-it, gemma-3-12b/27b-it, gemma-4 variants, Qwen3 4B/8B/14B/32B, Qwen3.5/3.6 variants, meta-llama/Llama-3.3-70B-Instruct, gpt-oss-20b/120b, GLM, Kimi, MiniMax, DeepSeek-V3.2, MiMo (Tables 4, 9 list 32 rows; 31 have an Artificial Analysis index, gemma-2-9b-it does not).

- Judge: GPT-5.5 Pro. Data generation/verification: Claude 4.6 Opus, Claude 4.7 Opus, GPT-5.5.

## Datasets
Varied Deception (TriviaQA-based; ~5,000 eval + 3,000 tuning); Azaria-Mitchell Facts-true-false; SciQ; Alpaca (calibration); three auditing datasets (above). Hosting: "We release our datasets, model organisms, and trained detectors" with the pointer `ai-safety-institute/lie-detection` (p.1).

## Baselines
Apollo, Unrelated Questions, CoT judge (and judge without CoT in Fig 6) vs the new DYL probe; Targeted Apollo (trained on Natarajan et al. 2026 contrastive data).

## Metrics
Balanced accuracy (main; at the Alpaca-1% threshold), AUROC, TPR; Spearman rho vs Artificial Analysis Intelligence Index.

## Key results
- Scaling on Varied Deception: all four detectors correlate positively with capability, Spearman rho 0.41-0.71, all p <= 0.031 (p.9-10).
- Prompted -> trained (same base models), median balanced accuracy (p.11): Apollo 0.85 -> 0.52; DYL 0.81 -> 0.65; Unrelated Qs 0.85 -> 0.50. AUROC: Apollo 0.91 -> 0.75; DYL 0.87 -> 0.75; Unrelated 0.93 -> 0.62. CoT judge 0.82 BA on model organisms (abstract), partly a selection artefact of CoT-based verification.
- Prompted Gender Secret on base Qwen 3.5 27B (App. K, p.27): Apollo BA 0.5, AUROC 0.68; Unrelated BA 0.51, AUROC 0.65-0.7; DYL BA 0.85, AUROC 0.9-0.93; CoT judge BA 0.86-0.9, AUROC 0.96. So Apollo/Unrelated fail on this behaviour style even when prompted; DYL's drop is due to fine-tuning.
- Per-model BA on Varied Deception (Table 9, p.28), small models relevant to us:
  - google/gemma-2-9b-it: Apollo 0.77, DYL 0.70, Judge 0.52, Unrelated 0.77.
  - google/gemma-3-12b-it: 0.74 / 0.72 / 0.59 / 0.79. gemma-3-27b-it: 0.81 / 0.78 / 0.60 / 0.78.
  - Qwen3-4B 0.64/0.68/0.85/0.74; Qwen3-8B 0.74/0.69/0.87/0.76; Qwen3-14B 0.87/0.80/0.92/0.76; Qwen3.5-4B 0.89/0.82/0.92/0.81; Qwen3.5-27B 0.95/0.93/0.97/0.76; Qwen3.6-27B 0.84/0.88/0.95/0.80.
  - Llama-3.3-70B: 0.84/0.74/0.53/0.84 (judge near chance on non-reasoning models).
- DYL question variants (Table 3, p.22): median BA 0.82 ("did you lie") vs 0.79 / 0.79.
- Targeted Apollo: median 0.84 -> 0.81, inconsistent per model (App. F).
- Best single-layer non-CoT detector on GLM 5.1 reached only 0.91 BA despite heavy optimisation (p.11).
- Gender-belief OOD generalisation (p.8): Cywinski et al. female organism assumes male 23% of the time; Liars' Bench Gender Secret (M) assumes male 49%; authors' Qwen 3.5 27B 60%, Qwen 3.6 27B 78%; Maths Sandbagger reasons about sandbagging on 94% of held-out maths questions.
- Label noise (App. H, p.24): a helpful-only model flagged 20% of WMDP questions as mislabelled, 8% ambiguous, 2% no correct answer (~one third problematic). On Liars' Bench Harm Pressure Choice (Llama 3.3 70B) the analyser disagreed with 13% of honest-labelled and 34% of lie-labelled samples.
- Llama-3.3-70B introspection (App. I): base model false-confesses on auditing questions (e.g. 3/11 sandbagging questions; 17.5-20% on AuditBench traits vs 0-2.5% for Qwen baselines); Llama-3.1-8B 6/11.

## Stated limitations (Sec 8)
No adversarial pressure on detectors; prompt-distilled organisms may resemble system-prompted behaviour and only two closely related base models; scaling results on prompted lying only. Also: belief verification gives only probabilistic evidence, so some lie labels may be wrong and a perfect detector may not reach 100% (p.9-10); roleplay prompts may induce sincere false belief.

## Relevance to hallucination-vs-lie separation
- Does NOT measure hallucination-vs-lie discrimination. Unknown-answer questions are **filtered out** before evaluation, so there are no hallucination samples in any testbed; negatives are honest (correct) answers. Detector performance therefore confounds "lie" with "false output".
- What it contributes:
  - The cleanest stated operationalization of "knows the answer" among the five papers: correct under a neutral prompt (Varied Deception, DYL training, Unrelated-Qs training). App. B adds guidance: verify beliefs across multiple contexts; avoid reflexive-lying setups; avoid elicitation that modifies beliefs (light prefills like "The answer is" are acceptable, answer-containing prefills are not). It explicitly says belief verification is needed "to determine whether a false statement constitutes a lie rather than error or uncertainty" (p.18).
  - The weak-hope framing openly allows that detectors may respond to "something correlated with lying" rather than lying itself -- our experiment tests exactly that for the falsehood/uncertainty correlate.
  - The judge prompt (App. M) is the only detector in these papers that explicitly instructs separating factual error from lie; it is reusable verbatim as a black-box baseline and as a labelling aid.
  - Warning on label noise: lie labels built from "correct once, wrong under pressure" can be substantially wrong (13-34% disagreement on Harm Pressure). We should require correctness across several neutral paraphrases/samples, not one.
- Reusable recipe for our experiment:
  - Matched design falls out directly: TriviaQA questions -> neutral-prompt answer. Correct under neutral + wrong under lie-inducing prompt = lie; wrong under neutral (and under honest prompt) = hallucination candidate. Same question pool, same model.
  - DYL probe: exact follow-up string, training on city->country questions with honest / lie-confess / lie-double-down prompts, answer-token activations, discard honest false confessions. Then test whether DYL scores differ between hallucinated and lied answers (the model should not "believe it lied" when hallucinating).
  - Apollo probe as specified here (last 5 tokens of truncated facts; mean over assistant tokens at run-time) and per-sample (not pooled-token) Alpaca 1% FPR calibration.
  - Model choice guidance: gemma-2-9b-it gives modest prompted-lie detection (Apollo 0.77, DYL 0.70 BA); Qwen3-14B (0.87/0.80), Qwen3.5-4B (0.89/0.82) and Qwen3.5/3.6-27B (0.84-0.95) do better and are plausible on 48GB (27B likely needs quantization -- not discussed in the paper). Avoid Llama-3.x for self-report-based labels (false confessions).
  - Report balanced accuracy at the calibrated threshold alongside AUROC, since thresholding is fragile.
